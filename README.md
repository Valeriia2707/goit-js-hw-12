Image Search Application 🖼️
A dynamic web application that allows users to search for high-quality images using the Pixabay API. The project focuses on handling asynchronous HTTP requests, implementing pagination, and providing a smooth user experience.

🚀 Features
Live Search: Search for any topic to get a gallery of relevant images.

Pagination: "Load more" functionality to fetch additional results dynamically.

Modal View: Lightbox integration to view images in full size (using basicLightbox).

Responsive Gallery: A fluid grid layout that adapts to different screen sizes.

UX Enhancements: Smooth scrolling after loading new content and error notifications via iziToast.

🛠 Tech Stack
JavaScript (ES6+): Core logic, including Fetch API and Async/Await.

HTML5 & CSS3: Semantic structure and modern styling.

Axios: For handling HTTP requests to the Pixabay API.

Libraries:

basicLightbox — for the image modal windows.

iziToast — for elegant user notifications and error handling.

SimpleLightbox — (if applicable) for gallery navigation.

📦 Getting Started
Clone the repository:

Bash
git clone https://github.com/valeriia2707/goit-js-hw-12.git
Open the project folder:

Bash
cd goit-js-hw-12
Install dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
🔑 API Reference
This project uses the Pixabay API. To run it locally, you may need to provide your own API key in the configuration file.
